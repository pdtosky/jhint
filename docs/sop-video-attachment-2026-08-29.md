# 작업표준서 영상 첨부 수정 로그

- 적용일: 2026-08-29
- 기능: 작업표준서 첨부자료에 MP4, WebM, MOV 영상 업로드·재생·삭제 추가
- 제한: 첨부자료 총 8개, 영상 파일당 최대 50MB
- 저장: 비공개 Supabase Storage `sop-media` 버킷
- 조회: 로그인 사용자가 1시간 유효한 임시 재생 주소로 조회
- 권한: 관리자·총무·품질 화면에서 업로드, 인증된 작업자 화면에서 조회
- 보호: 영상은 운영 `app_state` JSON에 넣지 않고 경로·파일정보만 저장
- 삭제: 작업표준서에서 영상을 제외해 저장하거나 문서를 삭제한 뒤 저장 성공 시 Storage 파일 정리
- 기존 사진: 기존 8장 첨부와 자동 압축 동작을 그대로 유지
- 검증: 문법 검사, 영상 전용 회귀 테스트, 전체 테스트, 로컬 브라우저 확인, 운영 Storage 정책 확인
